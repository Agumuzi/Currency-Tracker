# Security Policy

## Supported versions

Security reports are reviewed against the **latest GitHub Release** of Currency Tracker. Older releases may not receive fixes. See [Releases](https://github.com/Agumuzi/Currency-Tracker/releases).

## Private reporting

Use [GitHub private vulnerability reporting](https://github.com/Agumuzi/Currency-Tracker/security/advisories/new) if it is enabled.

If the private reporting option is unavailable, [open a public issue requesting a secure contact method](https://github.com/Agumuzi/Currency-Tracker/issues/new), **without disclosing a vulnerability or sharing any secrets**. Do not post API keys, account information, private user data, logs containing credentials, or working exploit details in public issues.

Useful information: affected app version, macOS version, expected and observed behavior, potential impact, and a minimal reproduction without sensitive data. Responses and fixes depend on maintainer availability; no fixed SLA is offered.

## Relevant areas

Examples include locally stored API credentials, imported or exported settings, global text selection/Accessibility handling, network provider responses, and update download or checksum verification.

A faulty exchange-rate feed or inaccurate provider response is not necessarily a vulnerability in this application; report ordinary bugs through [Issues](https://github.com/Agumuzi/Currency-Tracker/issues).
