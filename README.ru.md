Currency Tracker — приложение для macOS в строке меню, которое показывает курсы валют, помогает быстро конвертировать суммы и умеет конвертировать выделенный текст из других приложений на уровне системных служб. Оно рассчитано на пользователей, которые регулярно следят за небольшим набором валютных пар и хотят держать этот рабочий процесс рядом со строкой меню.

## Что умеет приложение

- Держит выбранные валютные пары в одном клике от строки меню macOS.
- Позволяет показать или скрыть значок в строке меню и приостановить фоновую активность в настройках.
- Показывает компактные карточки с последним курсом, источником данных, временем обновления и индикатором роста или снижения.
- Каждую карточку можно раскрыть в график истории или двусторонний конвертер.
- Панель строки меню переключается между списком курсов и мультивалютным конвертером.
- Курсы можно показывать как `1 BASE` или `100 BASE`, с фиксированными 2, 4 или 6 знаками после запятой.
- Валютные пары можно добавлять, удалять, сортировать и искать в ISO-каталоге валют, поддерживаемом настроенными источниками данных.
- Выделенный текст из других приложений можно конвертировать через службы macOS или глобальное сочетание клавиш.
- Поддерживаются английский, упрощенный китайский, традиционный китайский, русский, японский, корейский, французский, немецкий, испанский, бразильский португальский и итальянский языки.
- Настройки и API-ключи хранятся локально на Mac и не помещаются в системную связку ключей.

## Основные возможности

### Курсы в строке меню

Выберите нужные валютные пары и держите их в компактной панели строки меню. Панель поддерживает прокрутку длинного списка, закрепление поверх окон, ручное обновление, разные режимы отображения самого элемента строки меню, а также настройку, которая скрывает значок в строке меню, сохраняя доступ через Dock.

### История и конвертация

Каждая карточка раскрывается в график недавней динамики или конвертер прямо внутри панели. В панели строки меню также есть отдельная страница мультивалютного конвертера, которая собирает список валют из вашей конфигурации и убирает дубликаты. Если исторические данные доступны, графики поддерживают диапазоны 7 дней, 1 месяц, 3 месяца, 6 месяцев и 1 год.

### Управление валютными парами

Окно настроек включает боковую панель и отдельные страницы для общего поведения, языка, валютных пар, валют конвертера, профилей, оповещений, политики обновления, источников данных, разрешений, обновлений, диагностики и запуска вместе с системой. Валюты конвертера могут следовать за выбранными валютными парами или управляться отдельно; фоновую активность можно приостановить, не отключая ручное обновление.

### Язык и поведение окон

Приложение следует языковым настройкам macOS для отдельных приложений и содержит страницу языка, которая напрямую открывает системные настройки Language & Region. Панель строки меню остается привязанной к значку в строке меню, а закрепленную панель и окно настроек можно менять по размеру, если список пар или локализованные подписи требуют больше места.

### Источники данных

По умолчанию Currency Tracker может работать с публичными резервными источниками. Для личного использования рекомендуемые расширенные источники — [Twelve Data](https://twelvedata.com/) и [Open Exchange Rates](https://openexchangerates.org/), потому что оба предоставляют бесплатные уровни: Twelve Data дает 800 бесплатных API credits в день, что примерно равно 100 полным обновлениям нескольких валютных пар в Currency Tracker, а Open Exchange Rates дает 1 000 бесплатных запросов в месяц.

Также можно добавить учетные данные для других популярных поставщиков, если нужны более широкий охват или надежность:

- [Twelve Data](https://twelvedata.com/)
- ExchangeRate-API
- [Open Exchange Rates](https://openexchangerates.org/)
- Fixer
- Currencylayer
- Пользовательские JSON API-шаблоны с заполнителями `{base}`, `{quote}` и `{key}`, безопасным вводом, состояниями включения/редактирования и встроенной проверкой подключения

### Профили и оповещения

Разные списки валютных пар и настройки обновления можно сохранять как профили и быстро переключать под разные сценарии. Оповещения по курсам могут следить за выбранными парами и запрашивать разрешение на уведомления при срабатывании порога.

### Обновления

Приложение умеет проверять GitHub Releases из настроек. После подтверждения пользователем пакет обновления скачивается, проверяется по SHA256, подготавливается, устанавливается, перезапускает приложение и очищает временные файлы. Поскольку приложение не подписано Apple Developer ID и не нотариально заверено Apple, системные разрешения macOS, например Accessibility, могут потребовать проверки после замены приложения; если Currency Tracker обнаружит, что ранее выданное разрешение больше не выглядит активным, после обновления внутри приложения откроется страница Permissions.

## Установка

### Homebrew

```bash
brew tap agumuzi/currency-tracker
brew install --cask currency-tracker
```

Homebrew устанавливает тот же ZIP из GitHub Release и проверяет его по SHA256 из cask. Для последующего обновления:

```bash
brew update
brew upgrade --cask currency-tracker
```

### Прямая загрузка

Скачайте `Currency-Tracker-1.6.2.zip` из последнего GitHub Release, распакуйте архив и переместите `Currency Tracker.app` в папку Applications.

### Разрешение первого запуска

Приложение распространяется через GitHub Releases. Оно подписано ad-hoc для целостности bundle, но не подписано Apple Developer ID и не нотариально заверено Apple. При первом запуске macOS может заблокировать приложение. Откройте:

`System Settings` -> `Privacy & Security` -> `Open Anyway`

Разрешите запуск `Currency Tracker`, затем подтвердите `Open`. После первого подтверждения последующие запуски обычно работают без дополнительных действий. При ручном обновлении или обновлении внутри приложения существующие данные Application Support сохраняются, но macOS может снова запросить подтверждение, потому что новый app bundle по-прежнему не подписан Developer ID и не нотариально заверен. Системные разрешения управляются macOS и не могут быть восстановлены приложением без участия пользователя; проверьте Settings -> Permissions, если после обновления изменились разрешения Accessibility, уведомлений или запуска при входе.

Если macOS не показывает `Open Anyway` и вы убедились, что приложение загружено из GitHub Release этого проекта, можно вручную убрать quarantine-атрибут:

```bash
xattr -dr com.apple.quarantine "/Applications/Currency Tracker.app"
```

Используйте эту команду только для программ из источника, которому доверяете.

## Требования

- macOS 14.0 или новее
- Доступ к интернету для обновления актуальных курсов

## Конфиденциальность

Currency Tracker ориентирован на локальное хранение данных. Настройки, выбранные пары, поведение обновления, профили, оповещения и API-ключи хранятся на вашем Mac. Ключи поставщиков сохраняются в локальных данных Application Support приложения, а не в системной связке ключей macOS. Приложение не загружает локальные файлы, содержимое буфера обмена или данные устройства на серверы, принадлежащие этому проекту.

Внешние поставщики курсов получают только те запросы, которые нужны для включенных вами источников данных.
